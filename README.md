# food-delivary-1
🍔 FlameBite – Food Delivery Website

FlameBite is a modern and responsive food delivery website designed to make ordering delicious food online simple, fast, and convenient. It allows users to explore food categories, discover popular restaurants, browse delicious dishes, and enjoy exciting offers.

🌐 Project Overview

FlameBite provides a user-friendly food ordering experience with an attractive interface, beautiful food images, interactive elements, and a modern design.

The website is designed using HTML, CSS, and JavaScript with a responsive layout that works across desktop, tablet, and mobile devices.

✨ Features
Modern Navigation Bar: Easy navigation with Home, Restaurants, Menu, Offers, and Contact sections.
Food Search: Search for your favorite food and restaurants.
Hero Section: Attractive landing page with food images and delivery location search.
Food Categories: Explore different categories such as Pizza, Burgers, Biryani, Chinese, Desserts, Ice Cream, Sandwiches, and Healthy Food.
Popular Restaurants: Discover restaurants with ratings, cuisine details, and delivery information.
Popular Dishes: Browse delicious food items with images, descriptions, prices, and ratings.
Special Offers: Enjoy promotional discounts and offers using the FOOD50 coupon code.
